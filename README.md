# The Style Vault - Fashion Retail Website 👗

A responsive fashion retail website built using **HTML5 and CSS3**.  
This project showcases a modern online clothing store design with product categories, promotions, shopping cart interface, and a fashion assistant chatbot layout.

## 🌟 Features

- Responsive fashion retail website design
- Men's, Women's, and Kids' clothing sections
- New arrivals and promotional products
- Product cards with images and details
- Shopping cart user interface
- Product details modal design
- Fashion assistant chatbot interface
- Price filter and sorting options
- Mobile-friendly responsive layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive Web Design

## 📂 Project Files

- `clothing.html` - Main website page
- `clothing.css` - Styling file
- `.avif` files - Product images
- `colab.jpeg` - Header background image

## 🚀 How to Run

1. Download or clone this repository.
2. Open `clothing.html` in your browser.
3. View the fashion retail website.
